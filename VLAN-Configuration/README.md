# VLAN Configuration Project

## Objective
To configure Virtual Local Area Networks (VLANs) and establish communication between devices within the same VLAN.

## Tools Used
- Cisco Packet Tracer

## Features
- VLAN Creation
- Port Assignment
- Network Segmentation
- Connectivity Testing

## Result
Devices within the same VLAN communicated successfully, demonstrating proper network segmentation.
